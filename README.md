# Slate

> A high-performance desktop application for deep-focus code reviews. Reclaim the review process from sluggish web interfaces and AI noise.

## The Name

Slate is named after the **Sheikah Slate**, an ancient artifact from *The Legend of Zelda: Breath of the Wild*. Much like its namesake — a tablet that grants its bearer extraordinary perception and control — Slate gives senior engineers and maintainers an artifact to perceive code changes with clarity, precision, and power.

## Vision

The modern code review experience is broken:

- **Sluggish web interfaces** that load endlessly, crash unexpectedly, and drown you in UI chrome
- **AI-generated noise** that floods PRs with auto-generated comments, making it impossible to find the signal
- **Context switching** that kills deep focus — the state where real code quality lives

Slate is the command center for engineers who care about craft. It's built for **deep-focus reviews**: no distractions, no bloat, just you and the code.

## Features

- ⚡ Blazing fast native performance
- ⌨️ 100% keyboard-driven workflow
- 🔇 Intelligent noise filtering — see what matters, ignore the rest
- 🎯 Deep integration with GitHub PRs

## Tech Stack

- **Electron** — Cross-platform desktop runtime
- **TypeScript** — Type-safe codebase
- **Webpack** — Optimized bundling

## Getting Started

```bash
# Install dependencies
npm install

# Run in development mode
npm start

# Build for distribution
npm run make
```
